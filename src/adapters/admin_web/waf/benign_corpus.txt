# 格式：每行一筆，前綴代表請求的哪個部分：
#   U|  URL 路徑與查詢字串（GET，無特殊標頭）
#   R|  Referer 標頭（請求路徑為 /courses）
#   C|  Cookie 標頭（請求路徑為 /courses）
#   J|  JSON 本體（POST application/json）

# 非 ASCII 字元會在測試中自動做百分比編碼（與瀏覽器送出的格式相同）。
