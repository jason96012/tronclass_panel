jasonserver：讓 Tronclass 作業、公告與教材 自己找上你

jasonserver 是一套自架的課程自動化面板。它用你自己的 iClass 帳號持續盯著每一門課—— 作業快截止、老師發布公告或上架教材時，第一時間用 LINE、Discord 或瀏覽器推播通知你， 教材自動收進雲端硬碟，公告幫你摘要與翻譯。

登入面板 → 運作方式

面板內容需要登入才能使用；這一頁是公開介紹。支援桌上型與手機瀏覽器，也可加入主畫面當 App 使用。

jasonserver 的主要功能

從作業、公告到教材，把 Tronclass 上每天要手動巡一輪的事情自動化。

🔔

即時推播通知

作業快到期、老師發布公告或教材上架時立刻推播：課程名稱、事件內容、時間與前往連結一次附上，不必再盯著手機刷新。

⏰

作業與測驗截止提醒

彙整所有課程的作業、測驗與待辦，標示已繳／未繳與截止時間，並在到期前提醒，避免漏交。

☁️

教材雲端硬碟

一鍵把 iClass 當學期教材匯入伺服器（依系所／課程自動分類），支援線上預覽、分享連結、WebDAV 與資料夾管理。

📣

公告摘要與翻譯

課程公告集中顯示，可一鍵 AI 摘要重點、翻譯成中文，附件直接在面板內預覽或下載。

🗓️

課表、學分與每日摘要

課表匯入與提醒、學分統計、每日早晨摘要，一頁看完今天該做什麼。

🔐

多帳號與安全機制

多個 iClass 帳號同時監控、通行密鑰（Passkey）登入、登入裝置管理與 IP 黑名單，異常登入會留下紀錄與告警。

三個步驟就能用

jasonserver 以「自架」為前提設計：面板、資料與教材都在你自己的伺服器上。

1

加入你的 iClass 帳號

在面板的帳號設定輸入學校 iClass 帳號與密碼，jasonserver 會保存登入 session 來查詢課程資訊（不儲存明文密碼）。

2

選擇通知方式

綁定 LINE、Discord 或開啟瀏覽器推播，並設定要提醒的事件：作業截止、公告、教材更新等。

3

回到面板看總覽

儀表板會顯示作業待辦與截止倒數、最近的公告與教材更新；需要教材時就到教材雲端硬碟下載或線上預覽。

常見問題

關於 jasonserver 最常被問到的幾件事。

jasonserver 是什麼？

jasonserver 是一套自架的 Tronclass（淡江 iClass）課程自動化面板。它用你自己的 iClass 帳號持續整理課程資訊，在作業即將截止、老師發布公告或上架教材時，透過 LINE、Discord 或瀏覽器推播即時通知你。

要怎麼登入？

打開 面板登入頁，輸入在 jasonserver 設定的帳號密碼，或使用通行密鑰（Passkey）登入。面板本身需要登入才能使用，公開的只有這一頁介紹。

支援哪些學校或平台？

目前主要針對淡江大學的 iClass（Tronclass）站台調校，包含課程活動、作業與測驗、公告、教材、課表與學分 API。只要是 Tronclass 體系且有相同端點，也能透過設定站台網址使用。

通知會送到哪裡？

可選擇 LINE、Discord、瀏覽器 Web Push，或只收每日摘要。作業即將截止、老師發布公告或教材上架時，通知會附上課程名稱、事件內容與時間，並提供直接前往該堂課的連結。

我的資料存在哪裡？

面板與資料庫都架在自己的伺服器上（SQLite），iClass 的登入 session 只保存在該伺服器，用來代替你查詢課程資訊。教材檔案存於伺服器上的教材雲端硬碟，可用瀏覽器或 WebDAV 存取。

手機上可以用嗎？

可以。整站支援手機瀏覽，並能安裝成 PWA 加入主畫面；公告、教材預覽與通知在手機上都是全螢幕、觸控優化的版本。

要進面板了嗎？

jasonserver 的儀表板、教材雲端硬碟與公告都在登入後使用。
