僅限台灣地區存取

Tronclass Dashboard 的管理後台目前只開放台灣地區的網路連線存取。

這是依連線所在地區做的存取限制，不代表你的 Dashboard 帳號已被刪除、停用或列入黑名單。
系統判斷這次連線的位置：__GEO_LOCATION__

可能原因

  • 目前人在國外（出國旅遊、交換、工作等），透過當地網路直接連線。
  • 使用了會把連線位置顯示為國外的服務（例如部分 VPN、代理伺服器）。
  • 所在地的網路服務商，把連線路由判斷成境外出口。
人在國外、需要存取？
請改用能連回台灣的網路方式（例如連回台灣的 VPN），或按下方按鈕聯絡管理員，請他視情況暫時放行這個連線，或在「IP 黑名單」管理頁關閉「僅限台灣 IP 存取」開關。

錯誤代碼：ACCESS_DENIED_GEO_RESTRICTED
