國外 IP 一律擋下
開啟時，非本國（預設僅台灣）的 IP 連進 /admin 會直接看到拒絕存取頁面；公開分享連結、搜尋引擎、第三方登入串接端點不受影響。查不出 IP 所在國家時（服務逾時等）一律放行，不會因此把整個台灣鎖在外面。

雲端主機／VPS 出口 IP 一律擋下（全站）
開啟時，判定為雲端主機、VPS 或機房代管商出口的連線（例如 AWS、Google Cloud、Azure 或其他 VPS 業者，不限特定幾家）一律看到拒絕存取頁面；範圍是整個網站，不是只有 /admin。查不出來源資訊時（服務逾時等）一律放行，不會因此錯擋真人。
存取放行申請 被「僅限台灣 IP」或「封鎖雲端／VPS機房 IP」擋下的訪客按了「聯絡管理員」才會出現在這裡（兩種擋法共用同一份待處理清單）；同一筆 Discord 也會收到通知與按鈕，兩邊處理一筆即可。按「暫時放行」只對這個 IP 生效，不是關掉整個限制。短時間內出現太多不同來源 IP 的申請時，會自動暫停逐筆通知，改成只提醒一次，避免洗版；按下方「清空並恢復通知」後才會再逐筆通知。
