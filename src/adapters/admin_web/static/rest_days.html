判定規則

每個帳號的監控迴圈在每一輪等待前都會用「今天的日期」跑一次下面的順序，命中就整天不自動輪詢；休息日期間最多每 30 分鐘重新檢查一次，因此 config/holidays.json 改完不用重啟。

寒暑假／停課區間

開學日自動恢復

內建區間依淡江大學 115 學年度行事曆（1150410 第 208 次行政會議通過）。「恢復偵測」= 區間結束後第一個上課日（已跳過週末與國定假日）。

內建國定假日

-

依行政院人事行政總處《政府行政機關辦公日曆表》，含補假日與連假中的週間日。已過去的日期會淡化顯示。

-
