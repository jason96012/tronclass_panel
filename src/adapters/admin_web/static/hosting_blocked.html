偵測到雲端／機房連線

Tronclass Dashboard 目前不開放雲端主機、VPS 或機房代管商出口的連線存取。

這是依連線來源「是不是雲端／機房 IP」做的存取限制，不代表你的 Dashboard 帳號已被刪除、停用或列入黑名單。
系統判斷這次連線的來源：__HOSTING_LOCATION__

可能原因

  • 透過雲端虛擬主機（例如 AWS、Google Cloud、Azure 或其他 VPS 業者）連線，而不是家用寬頻、校園網路或行動網路。
  • 使用了架在雲端機房的 VPN、代理伺服器或跳板主機連線。
  • 自動化工具、掃描器或機器人從機房 IP 發出的連線（這類來源本來就是這項限制主要想擋下的對象）。
你是真人、確實需要從這個連線存取？
請改用一般家用寬頻、校園網路或行動網路連線，或按下方按鈕聯絡管理員，請他視情況暫時放行這個連線，或在「IP 黑名單」管理頁關閉「封鎖雲端／VPS機房 IP」開關。

錯誤代碼：ACCESS_DENIED_HOSTING_IP
